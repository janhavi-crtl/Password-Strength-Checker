# 🔐 Password Strength Checker

A Python application that evaluates password strength based on common cybersecurity best practices.

---

## 📌 Features

- ✅ Minimum length validation
- 🔠 Uppercase letter detection
- 🔡 Lowercase letter detection
- 🔢 Number detection
- 🔒 Special character detection
- 📋 Password improvement suggestions

---

## 🛠 Technologies Used

- Python 3
- Regular Expressions (`re` module)

---

## 📂 Project Structure

```
Password-Strength-Checker/
│── password_checker.py
│── README.md
│── requirements.txt
│── .gitignore
```

---

## ▶️ How to Run

```bash
python password_checker.py
```

Enter a password when prompted to receive a strength report.

---

## 💡 Example

Input:

```
Welcome123
```

Output:

```
Password Strength Report
------------------------------
🟡 Moderate Password

Suggestions:
- Add at least one special character.
```
